# Treebars SDKs

The client SDKs for [Treebars](https://treebars.com): events, identity, sessions, in-app messages and push.

| Platform | Install |
|---|---|
| Web — [`web`](web) | `npm install @treebars/web-sdk` |
| React Native | coming soon |
| iOS | coming soon |
| Android | coming soon |

Every SDK shares one version number, and a tag here marks each release. Each one's source appears here when it is
released.

Documentation: [treebars.com/docs](https://treebars.com/docs)

This repository is published from Treebars' own, so pull requests cannot be merged here directly — open an issue
and we will carry the change across.
